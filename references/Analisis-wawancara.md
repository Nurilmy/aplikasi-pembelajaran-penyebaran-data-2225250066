# ANALISIS HASIL WAWANCARA SISWA

## 1. Sumber Data
Sumber: Wawancara siswa S01.
Materi: Penyebaran Data.
Kelas saat mempelajari materi: VIII.

## 2. Temuan Wawancara

Siswa mengalami kesulitan dalam:
- Menentukan posisi kuartil.
- Mengurutkan data.
- Menentukan median.
- Memahami data ganjil dan genap.
- Mengidentifikasi nilai terbesar dan terkecil.

## 3. Hambatan Pembelajaran

- Instruksi terlalu panjang.
- Tabel dan informasi berjauhan.
- Penggunaan warna berlebihan.
- Penjelasan terlalu cepat.
- Langkah penyelesaian sulit diingat.

## 4. Kebutuhan Siswa

- Contoh penyelesaian bertahap.
- Petunjuk ketika menjawab salah.
- Pengurutan data otomatis.
- Penanda median dan kuartil.
- Tampilan sederhana.
- Latihan dengan variasi data.

## 5. Pemetaan Kebutuhan dan Fitur

| Kebutuhan | Fitur |
|---|---|
| Sulit menentukan Q1 dan Q3 | Visualisasi kuartil |
| Langkah sering tertukar | Pembelajaran bertahap |
| Kesulitan mengurutkan data | Pengurutan otomatis |
| Instruksi terlalu panjang | Instruksi sederhana |
| Membutuhkan bantuan | Petunjuk bertingkat |
| Membutuhkan latihan | Latihan interaktif |

## 6. Kesimpulan

Berdasarkan wawancara awal, aplikasi Ruang Data
dirancang untuk memberikan pengalaman belajar
yang sederhana, terarah, dan bertahap.

Aplikasi diharapkan dapat membantu mengurangi
beban kognitif siswa dan mendukung perkembangan
literasi matematika.

Efektivitasnya tetap perlu dibuktikan melalui
pengujian dan penelitian lebih lanjut.
