# SYSTEM REQUIREMENTS

## 1. Kebutuhan Fungsional

1. Aplikasi menampilkan halaman beranda.
2. Aplikasi menyediakan pilihan materi.
3. Aplikasi menampilkan penjelasan konsep.
4. Aplikasi menyediakan contoh bertahap.
5. Aplikasi menyediakan latihan soal.
6. Aplikasi memberikan petunjuk.
7. Aplikasi memeriksa jawaban.
8. Aplikasi menampilkan pembahasan.

## 2. Kebutuhan Nonfungsional

1. Responsif pada smartphone dan desktop.
2. Tampilan sederhana dan konsisten.
3. Navigasi mudah dipahami.
4. Informasi mudah dibaca.
5. Perhitungan harus akurat.
6. Tidak membutuhkan login pada versi awal.

## 3. Pengujian

- Jangkauan data 6, 8, 5, 10, 7 = 5.
- Median data 4, 6, 7, 8, 9, 11, 13 = 8.
- Q1 data 2, 4, 5, 7, 8, 10, 12 = 4.
- Q3 data tersebut = 10.
- IQR = 10 - 4 = 6.

Metode kuartil menggunakan median-of-halves.
