# ARCHITECTURE APLIKASI

## 1. Teknologi
- React JS
- Vite
- JavaScript
- CSS
- HTML

## 2. Struktur Sistem

src/
  App.jsx
  App.css
  index.css
  main.jsx

## 3. Komponen Utama

App.jsx:
Mengatur halaman dan interaksi pengguna.

main.jsx:
Menjalankan aplikasi React.

App.css:
Mengatur tampilan komponen.

index.css:
Mengatur gaya dasar aplikasi.

## 4. Alur Sistem

Pengguna
   ↓
Beranda
   ↓
Memilih Materi
   ↓
Mempelajari Konsep
   ↓
Melihat Contoh
   ↓
Mengerjakan Latihan
   ↓
Mendapatkan Umpan Balik
   ↓
Mengulang atau Melanjutkan Materi

## 5. Penyimpanan
Versi awal menggunakan state React.
Belum menggunakan database atau backend.
