# ROADMAP PENGEMBANGAN

## Tahap 1: Analisis Kebutuhan
- Mengumpulkan hasil wawancara.
- Mengidentifikasi kesulitan siswa.
- Menentukan kebutuhan aplikasi.

## Tahap 2: Perencanaan
- Membuat PRD.
- Membuat desain aplikasi.
- Menentukan teknologi.

## Tahap 3: Pengembangan
- Membuat halaman beranda.
- Membuat halaman materi.
- Membuat contoh bertahap.
- Membuat latihan interaktif.

## Tahap 4: Pengujian
- Menguji fungsi aplikasi.
- Menguji perhitungan matematika.
- Menguji tampilan smartphone.
- Menguji tampilan desktop.

## Tahap 5: Evaluasi
- Menguji kemudahan penggunaan.
- Mengevaluasi cognitive load.
- Mengukur kemampuan literasi matematika.

## Tahap 6: Penyempurnaan
- Memperbaiki kekurangan.
- Menambahkan fitur berdasarkan hasil evaluasi.
- Menyiapkan aplikasi untuk digunakan siswa.
