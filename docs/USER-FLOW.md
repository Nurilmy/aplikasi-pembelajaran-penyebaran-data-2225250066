# USER FLOW APLIKASI

## 1. Membuka Aplikasi
Siswa membuka aplikasi melalui browser.

## 2. Beranda
Siswa melihat pilihan materi pembelajaran.

## 3. Memilih Materi
Siswa memilih salah satu materi:
- Jangkauan.
- Median.
- Kuartil.
- Jangkauan Interkuartil.

## 4. Pembelajaran
Siswa membaca konsep dan rumus.

## 5. Contoh
Siswa mengikuti penyelesaian secara bertahap.

## 6. Latihan
Siswa mengerjakan soal yang tersedia.

## 7. Petunjuk
Siswa dapat meminta petunjuk apabila mengalami
kesulitan.

## 8. Umpan Balik
Aplikasi memeriksa jawaban dan memberikan
pembahasan.

## 9. Selesai
Siswa dapat melanjutkan soal atau mempelajari
materi lainnya.
