# RUANG DATA
## Aplikasi Pembelajaran Matematika

### Deskripsi
Ruang Data merupakan aplikasi pembelajaran matematika
berbasis web yang dirancang untuk membantu siswa
memahami materi penyebaran data.

Aplikasi ini berfokus pada penyajian materi secara
bertahap, visualisasi, latihan interaktif, dan
pemberian petunjuk untuk membantu mengurangi beban
kognitif siswa.

### Tujuan
1. Membantu siswa memahami konsep penyebaran data.
2. Menyajikan materi secara sederhana dan bertahap.
3. Membantu siswa mengembangkan literasi matematika.
4. Memberikan latihan dan umpan balik.

### Materi
1. Jangkauan (Range).
2. Median.
3. Kuartil.
4. Jangkauan Interkuartil (IQR).

### Teknologi
- HTML
- CSS
- JavaScript
- React JS
- Vite

### Persyaratan
- Node.js
- npm
- Visual Studio Code
- Browser

### Cara Menjalankan
1. Buka terminal VS Code.
2. Jalankan npm install.
3. Jalankan npm run dev.
4. Buka alamat localhost yang diberikan Vite.

### Build Aplikasi
Jalankan:

npm run build

### Pengembangan
Aplikasi dikembangkan berdasarkan analisis kebutuhan
awal dari wawancara siswa.

### Catatan
Efektivitas aplikasi terhadap cognitive load dan
literasi matematika perlu diuji melalui penelitian
lebih lanjut.
