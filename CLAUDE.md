# PEDOMAN PENGEMBANGAN APLIKASI RUANG DATA

## 1. Identitas Proyek
Nama: Ruang Data

Jenis: Aplikasi pembelajaran matematika berbasis web.

Target: Siswa SMP.

Materi: Penyebaran Data.

## 2. Tujuan Pengembangan
Mengembangkan aplikasi pembelajaran matematika yang
membantu mengurangi beban kognitif siswa melalui
penyajian materi secara bertahap, sederhana, dan
terstruktur.

Aplikasi juga diarahkan untuk meningkatkan kemampuan
literasi matematika siswa.

## 3. Teknologi
- React JS
- Vite
- JavaScript
- CSS
- HTML

## 4. Prinsip Pengembangan
1. Gunakan bahasa sederhana.
2. Sajikan satu konsep dalam satu tahap.
3. Hindari informasi yang tidak diperlukan.
4. Letakkan instruksi berdekatan dengan soal.
5. Gunakan warna secara konsisten.
6. Berikan petunjuk secara bertahap.
7. Pastikan aplikasi responsif di smartphone.
8. Gunakan contoh yang berkaitan dengan kehidupan
   sehari-hari.

## 5. Materi Pembelajaran
- Jangkauan.
- Median.
- Kuartil.
- Jangkauan Interkuartil.

## 6. Ketentuan Coding
- Gunakan komponen React.
- Pisahkan CSS dari JSX.
- Gunakan nama variabel yang mudah dipahami.
- Hindari kode yang tidak diperlukan.
- Pastikan seluruh tombol berfungsi.
- Pastikan tidak terdapat error saat build.

## 7. Evaluasi
Aplikasi perlu diuji kepada siswa untuk mengetahui
kemudahan penggunaan, beban kognitif, dan perkembangan
kemampuan literasi matematika.
